# 📝 To-Do List App

A simple Python To-Do List application.

## ✨ Features

- Add a task
- View all tasks
- Remove a task
- Exit the application

## 🛠️ Technology Used

- Python
- List
- While Loop
- If-elif-else
- User Input

## ▶️ How It Works

1. Choose an option from the menu.
2. Add your task.
3. View your tasks.
4. Remove a task when completed.
5. Exit the application.
